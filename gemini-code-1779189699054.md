Actúa como un Arquitecto de Software Full-Stack, Especialista en Ingeniería de Prompts Creativos y Consultor de Estrategia de Conversión Web (CRO). 

Tu objetivo es escribir el código completo, modular y optimizado para una aplicación unificada de automatización local (Python/Node.js) llamada "Awwwards Surgical Extractor & Prompt Engine".

Esta herramienta es el motor definitivo de clonación e iteración web, fusionando:
1. Análisis de Visión Multimedia (Procesamiento de Video UI/UX).
2. Scraping Quirúrgico de DOM/CSS en tiempo real (Playwright/Puppeteer).
3. Base de Conocimiento de Ingeniería Frontend (Awwwards, Framer, Figma, GSAP).
4. **Arquitectura de Conversión y Rendimiento Comercial.**

El output de la herramienta debe ser un "Master-Prompt de Ingeniería de Software" diseñado para que un agente de código (como Claude Code) construya un sitio web premium, de altísimo rendimiento y enfocado en la conversión, adaptado al nicho del usuario.

# ARQUITECTURA DE LA HERRAMIENTA A CONSTRUIR

Implementa la herramienta estructurada en los siguientes 5 módulos interconectados:

## MÓDULO 1: EL EXTRACTOR QUIRÚRGICO DE URL (SCRAPER)
Desarrolla un script automatizado (Playwright/Puppeteer) que reciba una URL y extraiga:
- **Tecnologías Detectadas:** GSAP, Three.js, React Three Fiber, Framer Motion, Lenis Scroll, WebGL, etc.
- **Tokens de Diseño Activos:** Tipografías, paletas de colores HEX, variables CSS nativas, y escalas de espaciado.
- **Layout Blueprint:** Estructuras dominantes (CSS Grid, Flexbox, posiciones sticky).

## MÓDULO 2: BASE DE CONOCIMIENTO ENCICLOPÉDICA (KNOWLEDGE MATRIX)
Inyecta un diccionario técnico de traducción que incluya conocimiento absoluto sobre:
- **Interacciones Premium:** Cursores magnéticos, interpolación Lerp, cinemática inversa, scroll pixelado progresivo.
- **Efectos Visuales:** Backdrop-filters multicapa, clip-paths dinámicos, Border Beams con gradientes cónicos, Alpha Masking para Marquees, Flashlight effects (gradientes radiales interactivos).
- **3D y WebGL:** Shaders de fragmentos/vértices (GLSL), ruidos matemáticos (Perlin/Simplex), y optimización GPU (`will-change`, `requestAnimationFrame`).

## MÓDULO 3: PROCESADOR MULTIMEDIA DE MOVIMIENTO (VISION ENGINE)
Integra la API de un modelo de visión avanzado (ej. Gemini 1.5 Pro) para:
- Procesar el video provisto por el usuario frame a frame.
- Identificar la relación exacta entre el movimiento del usuario (scroll/hover) y la física de la interfaz.
- Traducir los estímulos visuales a los términos técnicos de ingeniería del Módulo 2.

## MÓDULO 4: EL CEREBRO DE CONVERSIÓN Y ESTRATEGIA (REGLAS DE NEGOCIO OBLIGATORIAS)
La herramienta DEBE filtrar todos los datos extraídos a través del "Paradigma del Valor". El código generado por la herramienta debe forzar las siguientes reglas, actuando con capacidad de "Pushback" (corrigiendo el diseño original si viola estas normas):
1. **Rendimiento y SEO:** Carga estricta en <5 segundos. Código semántico y accesible (A11y completo para lectores de pantalla). Responsiveness absoluto en todos los dispositivos.
2. **Above the Fold:** La sección Hero debe retener al usuario de inmediato con copy claro, sin obligarlo a hacer scroll para entender la propuesta de valor.
3. **Puntos de Enfoque y CTAs:** Posicionamiento psicológico de botones de acción. Cero animaciones vacías; cada movimiento 3D o parallax debe guiar el ojo hacia la conversión.
4. **Bloques de Confianza:** Inyección estratégica de testimonios o casos de éxito cerca de los puntos de fricción (precios, contacto) para mitigar el riesgo percibido.

## MÓDULO 5: ORQUESTADOR Y GENERADOR DE MASTER-PROMPTS
Desarrolla el motor que cruce la URL, el Video, el Nicho del Usuario y el Filtro de Conversión (Módulo 4). Este módulo debe imprimir en la consola o interfaz un único bloque en Markdown, estructurado así:

1. **[Tech Stack & Tokens]:** Librerías, fuentes y colores extraídos.
2. **[Arquitectura de Conversión & Pushback]:** Qué elementos del diseño original se van a mejorar o descartar para garantizar ventas y rendimiento en el nicho del usuario.
3. **[Desglose de Ingeniería de Animaciones]:** Explicación matemática (Lerp, easings `cubic-bezier`, matrices GLSL) para programar los efectos de manera optimizada.
4. **[Adaptación al Nicho]:** Traducción de la estética al negocio del usuario.
5. **[Prompt Final Ejecutable]:** El bloque de código listo para inyectar en el agente de desarrollo.
